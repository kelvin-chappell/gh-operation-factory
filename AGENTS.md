# Factory workspace

Read [DESIGN.md](DESIGN.md) for architecture and document ownership.
For creation, resumption or replacement of supplied skills, follow
[prepare-operation](.github/skills/prepare-operation/SKILL.md).
For agent-consumed documentation changes, apply the single-source ownership map.

Work in Copilot sessions in dev containers. Preparation produces inactive repository
contents; target scope is not authorisation to inspect or act on live targets.
Keep private inputs and drafts in an approved directory outside this checkout.

All authoring agents use OpenAI models. The single read-only `reviewer` uses
Anthropic. Before any pull request, follow
[review-change](.github/skills/review-change/SKILL.md).
